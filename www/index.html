Serveur de suivi sécurisé

Serveur privé de l’entité de contrôle (un seul domaine HTTPS). Si renseigné, la position est envoyée à ce serveur et le lien du convoi pointe dessus. Laisser vide pour utiliser le mode public ci-dessous.

Adresse de la page de suivi

Adresse où est hébergé le fichier suivi.html (par exemple GitHub Pages). Elle sert à fabriquer le lien du convoi. Sans elle, tu peux quand même donner le code : il se saisit sur la page de suivi.
